# Python & AI Practice Projects

A collection of hands-on Python, AI, and Machine Learning projects completed as part of my DigiSkills 3.0 coursework (AI using Python – AIP301).

## Projects

### 1. Python Fundamentals — Loops, NumPy & OOP
- Built a sales tax calculator using loops and conditional logic to apply tiered tax rates
- Practiced data handling with NumPy, including array creation and data type conversion
- Designed a Bank Account Management System using Object-Oriented Programming (Customer and Account classes), supporting deposits, withdrawals, and balance tracking

**Skills used:** Python, NumPy, Object-Oriented Programming (OOP), Conditional Logic

### 2. Titanic Survival Prediction — Data Analysis & Machine Learning
Analyzed the Titanic passenger dataset to explore survival patterns and built a Support Vector Classifier (SVC) to predict passenger survival. Performed data cleaning, exploratory data analysis, and model evaluation using accuracy, precision, recall, F1-score, and a confusion matrix. Created visualizations analyzing survival by gender, passenger class, and fare distribution.

**Skills used:** Python, Pandas, Scikit-learn, Matplotlib, Seaborn, Machine Learning
